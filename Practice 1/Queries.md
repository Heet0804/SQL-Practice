# Cricket League SQL Practice — Queries (Q1–Q60)

Note: Table/column names are used as created (`CRICKET_LEAGUE`, `TEAMS`,
`PLAYERS`, `MATCHES`, `PERFORMANCES`, all uppercase, per the uploaded
`teams_table.sql` / `players_table.sql` / `matches_table.sql` /
`performances_table.sql` files). `USE CRICKET_LEAGUE;` is assumed before
every query. For CREATE PROCEDURE / CREATE TRIGGER blocks, remember to
switch the client delimiter (e.g. `DELIMITER //`) so the semicolons
inside the routine body don't end the statement early.

**Q50.**
```sql
SELECT t.TEAM_NAME, p.PLAYER_NAME, pr.total_runs
FROM (
    SELECT pl.TEAM_ID, pl.PLAYER_ID, SUM(pf.RUNS_SCORED) AS total_runs
    FROM PLAYERS pl
    JOIN PERFORMANCES pf ON pl.PLAYER_ID = pf.PLAYER_ID
    GROUP BY pl.TEAM_ID, pl.PLAYER_ID
) pr
JOIN (
    SELECT pl.TEAM_ID, MAX(team_runs.total_runs) AS max_runs
    FROM (
        SELECT pl2.TEAM_ID, pl2.PLAYER_ID, SUM(pf2.RUNS_SCORED) AS total_runs
        FROM PLAYERS pl2
        JOIN PERFORMANCES pf2 ON pl2.PLAYER_ID = pf2.PLAYER_ID
        GROUP BY pl2.TEAM_ID, pl2.PLAYER_ID
    ) team_runs
    JOIN PLAYERS pl ON pl.PLAYER_ID = team_runs.PLAYER_ID
    GROUP BY pl.TEAM_ID
) maxr ON pr.TEAM_ID = maxr.TEAM_ID AND pr.total_runs = maxr.max_runs
JOIN PLAYERS p ON p.PLAYER_ID = pr.PLAYER_ID
JOIN TEAMS t ON t.TEAM_ID = pr.TEAM_ID
ORDER BY t.TEAM_NAME;
```

**Q56.**
```sql
START TRANSACTION;

UPDATE TEAMS SET COACH_NAME = 'Ricky Ponting' WHERE TEAM_NAME = 'SYDNEY SIXERS';
UPDATE MATCHES SET VENUE = 'MCG' WHERE MATCH_ID = 2;

SELECT TEAM_NAME, COACH_NAME FROM TEAMS WHERE TEAM_NAME = 'SYDNEY SIXERS';
SELECT MATCH_ID, VENUE FROM MATCHES WHERE MATCH_ID = 2;

COMMIT;

-- If ROLLBACK had been issued instead of COMMIT, BOTH updates in this
-- transaction would have been undone together: the coach name would
-- revert to "Michael Clarke" and match_id 5's venue... (i.e. match_id 2's
-- venue would revert to whatever it was before this transaction). A
-- transaction is all-or-nothing, so ROLLBACK undoes every statement
-- since the last START TRANSACTION, not just one of them.
```

FROM PLAYERS p
JOIN PERFORMANCES pf ON p.PLAYER_ID = pf.PLAYER_ID
GROUP BY p.PLAYER_ID, p.PLAYER_NAME
HAVING SUM(pf.RUNS_SCORED) = (

        GROUP BY PLAYER_ID
        ORDER BY total_runs DESC
        LIMIT 1 OFFSET 1
